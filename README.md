** KejaHub

KejaHub is a sleek, modern, and responsive property management tenant dashboard. Designed with a mobile-first approach, it allows tenants to track their rent history visually, monitor upcoming utility bills, and manage their rental profile effortlessly.
---

## 🚀 Features

* **Interactive Analytics:** Visualizes historical rent payment trends using a lightweight, responsive dynamic bar chart.
* **Utility & Bill Tracking:** A receipt-style summary component detailing current water and electricity costs.
* **Smart Reminders:** Integrated notification prompts to help tenants never miss a utility deadline.
* **Responsive Layout:** Features a rigid, distraction-free navigation sidebar and adaptive content spacing that transitions beautifully from desktop grids to single-column mobile structures.

---

| Technology | Purpose | Implementation |

## 📸 Dashboard Preview Structure

The layout architecture is divided into three primary interface blocks:

1.  **Header Component:** Branding title (`KejaHub`) accompanied by quick-access user profiles and real-time notification hubs.
2.  **Navigation Sidebar (`<aside>`):** A slim, 64px fixed-width vertical panel holding centralized controls protected against layout shrinkage.
3.  **Core Application Grid:** A dual-column environment hosting interactive charting models side-by-side with micro-billing data modules.
